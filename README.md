## About the Research

This repository presents the published research on cross-column quantitative structure–retention relationship (QSRR) modeling using density functional theory (DFT) molecular descriptors and machine learning for chromatographic retention prediction.

The research investigates the relationship between molecular properties, chromatographic conditions, and retention behavior across RP-HPLC columns.

## Research Highlights

- Cross-column QSRR modeling for retention time prediction.
- Integration of DFT-derived molecular descriptors and chromatographic parameters.
- Evaluation of multiple machine learning regression methods.
- Analysis of molecular properties influencing chromatographic retention.

## Methodology

**Molecular Structures → DFT Descriptors → Chromatographic Data → Machine Learning → Retention Time Prediction**
